# Roshan Ingershal VR: Portfolio

File: `index.html`, `style.css`, `script.js`, `README.md`

## Running
Open `index.html` in a browser. No build process is required.

## Editing
- Email, GitHub, and LinkedIn links: the Contact section in `index.html`.
- Colors and fonts: the variables at the top of `style.css`.
- Hero chart and risk estimator: `script.js`.
